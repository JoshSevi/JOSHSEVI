## AI-Assisted Engineering Workflow

I use AI development tools selectively based on the task.

My typical workflow:

1. Understand the requirement and expected business outcome
2. Inspect the existing repository and engineering conventions
3. Break the work into small, testable implementation steps
4. Use the appropriate AI tool to support analysis or implementation
5. Review every meaningful generated diff
6. Run type checking, linting, automated tests, and production builds
7. Verify expected behavior and edge cases manually
8. Document the implementation and prepare a focused pull request

This allows me to benefit from AI-assisted development without sacrificing maintainability, correctness, security, or engineering judgment.

## Engineering Principles

* Understand the system before changing it
* Keep changes focused and reviewable
* Prefer type safety and explicit validation
* Test critical business behavior
* Protect authentication and data-access boundaries
* Communicate blockers and uncertainty early
* Treat feedback as part of the engineering process
* Deliver code that other engineers can understand and maintain
